# Bread Cooperative — Public Knowledge Base

This is a **public, read-only** view of the Bread Cooperative knowledge base.

Bread Cooperative is a worker-owned collective building financial tools for
cooperatives, NGOs, and solidarity-focused communities. Everything we build is
open source, funded by the tools themselves, and governed collectively.

Use the navigation to explore:

- **[About](about)** — what the cooperative is and how BREAD works
- **[Solidarity Tools](solidarity-tools)** — the Solidarity Fund and Stacks
- **[Member Projects](member-projects)** — the network we fund
- **[Governance](governance)** — how we make decisions
- **[Contributing](contributing)** — how to get involved
- **[Links](links)** — official links

> This site publishes only public-safe material. Internal records — people
> contact details, finances, peer reviews, tasks — are deliberately excluded.
